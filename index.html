04 / БЫСТРЫЙ СТАРТ

Новый компьютер. Знакомый VS Code.

Три шага — и можно возвращаться к коду.

01

Забери профиль

Один файл с настройками и выбранными расширениями. Установка расширений потребует интернета.

02

Импортируй в VS Code

Открой File → Preferences → Profiles. В меню рядом с New Profile выбери Import Profile…, укажи файл и нажми Create.

В русской версии: «Профили» → «Импортировать профиль».
03

Установи шрифт

Распакуй архив шрифта. Выдели все .ttf, нажми правой кнопкой → «Установить» (в Windows 11 — «Показать дополнительные параметры»). Перезапусти VS Code.

Скачать шрифт
Хочу перенести вручную+

В VS Code нажми Ctrl + Shift + P и найди Preferences: Open User Settings (JSON) / «Параметры: Открыть параметры пользователя (JSON)». Скопируй нужные настройки из файла. Полная замена содержимого заменит текущие пользовательские настройки — сохрани их копию, если они нужны.

Команды устанавливают расширения в текущий профиль VS Code. Python, Go и другие среды выполнения устанавливаются отдельно.
