# codekit — мой набор VS Code

Статический сайт с настройками, 20 расширениями со скриншотов и JetBrains Mono.
Работает без сборки и npm. Чтобы посмотреть, открой **index.html** в браузере.

## Опубликовать на GitHub Pages

1. Создай репозиторий на GitHub.
2. Загрузи **содержимое этой папки** в корень репозитория. `index.html` должен
   лежать в корне, а не во вложенной папке. Сохрани папки `assets` и `downloads`.
3. Открой **Settings → Pages**.
4. В **Source** выбери **Deploy from a branch**.
5. Выбери ветку **main** и папку **/(root)**, нажми **Save**.
6. Дождись публикации — GitHub покажет ссылку на сайт.

Все ссылки на ресурсы относительные: сайт работает и на `username.github.io`,
и на `username.github.io/repository/`. Файл `.nojekyll` отключает обработку Jekyll.
Если интерфейс загрузки GitHub пропустит этот скрытый файл, для текущей структуры
сайта это не помешает публикации.

## Что умеет сайт

- Выбирать расширения, искать их и фильтровать по категориям.
- Скачать `.code-profile` с настройками и выбранными расширениями.
- Скопировать полный `settings.json` или скачать его отдельно.
- Получить команду установки для PowerShell, CMD, Bash / Zsh.
- Открыть расширение в VS Code или Marketplace.
- Скачать JetBrains Mono и проверить лигатуры в интерактивном примере.
- Показать инструкции для Windows, macOS и Linux.
- Скачать полный набор в ZIP. В нём всегда все 20 расширений в виде списка
  и команд, независимо от текущего выбора на странице.

Сайт не устанавливает программы из браузера. Файл профиля импортируется в VS Code,
расширения скачиваются из Marketplace, шрифт устанавливается в операционную систему.
Скачиваемый набор не содержит VSIX и сред выполнения Python / Go.
Версии расширений не закреплены, так как их нет на исходных скриншотах.

## Перенос на другой компьютер

1. Нажми «Скачать профиль».
2. В VS Code открой **File → Preferences → Profiles**. На macOS —
   **Code → Settings → Profiles**.
3. В меню рядом с **New Profile** выбери **Import Profile…**, укажи файл
   `my-vscode.code-profile`, проверь содержимое и нажми **Create**.
4. Скачай шрифт, распакуй ZIP и установи все три `.ttf`. Перезапусти VS Code.

Названия команд и меню могут немного различаться в зависимости от языка
и версии VS Code. Документация: https://code.visualstudio.com/docs/configure/profiles

При ручном переносе открой пользовательские настройки командой
**Preferences: Open User Settings (JSON)**. Сохрани старые настройки перед заменой
или перенеси только нужные ключи. Команды установки расширений можно просто
скопировать из сайта в терминал. Запуск `.ps1` не обязателен.

## Обновить свой набор

1. Открой `data.js` и измени `settings` или список `extensions`.
2. При установленном Node.js запусти из папки сайта:

   ```sh
   node scripts/generate.mjs
   ```

3. Если изменилось количество расширений, поправь статические подписи в
   `index.html` (счётчики выбора пересчитываются автоматически).
4. Загрузи изменённые файлы на GitHub.

`core.js` содержит общую логику профиля, команд и фильтров. `app.js` — интерфейс.
Генератор не требует сторонних библиотек. Для публикации запускать его не нужно:
все файлы уже готовы в `downloads/`.
